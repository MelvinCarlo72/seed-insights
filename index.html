How to use it at Purple Seedlings

  1. Deploy SeedInsights so the feedback page has a public HTTPS address.
  2. Paste the full customer.html URL above.
  3. Generate and download the QR code.
  4. Display it at an approved reception or feedback point.
  5. Parents and guardians scan the code and submit feedback.
